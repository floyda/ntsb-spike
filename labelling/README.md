# Labelling sheets

Generated by the scripts; filled in by hand. `*.filled.csv` files are git-ignored
by default — remove that line from `.gitignore` if you want them versioned (they
are part of the evidence for the spike report, so probably yes once anonymised).

| File | Made by | You add |
|---|---|---|
| `leakage.csv` | `leakage sheet` | your guess at the cause, confidence, flagged sentences, then `correct` |
| `leakage.KEY.csv` | `leakage sheet` | nothing — don't open until you've guessed |
| `decidability.csv` | `oneshot` | `occurrence_correct`, `top3_correct`, `category` (A/B/C/D), `tool_that_would_fix_it` |

## How to label category on a miss

Ask: what did the model need that it didn't have?

- **A** — nothing. It was in the evidence; the model misread it. (Better prompt.)
- **B** — something else *in this case*: a docket document, the airframe's earlier history.
- **C** — something *outside this case*: similar past accidents, the weather report, a regulation.
- **D** — physical evidence only the NTSB had. Not fixable. Should have abstained.

When unsure between A and C, ask: "would a careful reader with only this text have got it?"
Yes → A. No → C.
